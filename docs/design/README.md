# 個人サイト リデザイン調査

調査日: 2026-11-17。目的は、wato787の個人サイトを全面的に見直すための判断材料を集めること。デザインの実装・採用方針は未決定。

## まず読む結論

**推奨仮説は「個人の編集室 / 技術のアーカイブ」**。ブログとプロフィールを軸に、タイポグラフィ、記事の選び方、余白のリズムで個性を作る。別案として「実験の作業机」「道具としての個人サイト」を比較したい。

流行をそのまま採用するより、本人の文章・制作物・写真を使った固有の編集が重要。AIには「おしゃれに」ではなく、読者、内容、参考のどこを取り入れるか、評価軸を渡す。色だけ異なる案ではなく、情報の構成から異なる案を比較する。

- [調査本文・参考資料](research.md): トレンド、デザインの基礎、参考の探し方、AIツール、サイトへの適用。
- [AI制作の実行手順・プロンプト](workflow.md): 次回そのまま使えるブリーフと検証項目。
- `.agents/skills/frontend-design`: Anthropic公式。固有の視覚表現を考えるためのスキル。
- `.agents/skills/web-design-guidelines`: Vercel公式。実装後のUIレビュー用スキル。

## 現状の前提（コードから確認）

Astro + TypeScript + microCMS。ホームはプロフィール→記事一覧→技術一覧→連絡先。ブログ一覧・記事ページがあり、スライドページは削除済み。

白背景、青アクセント、Noto Sans JP + JetBrains Mono、最大幅56rem。プロフィール写真と説明を2列にする構成、角丸と影、10–11pxのラベル、大きなセクション余白がある。ここで述べる現状はコードの把握であり、ブラウザーでの視覚監査・実測ではない。

リデザインの焦点は「何をする人か」と「何を読んでほしいか」の優先順位。実績の掲載は有効な候補だが、実在する公開可能な素材を確認してからにする。肩書き、実績、顧客、数字は捏造しない。

## 判断が必要なこと

1. 読者の中心は、技術者仲間・採用担当・仕事の依頼者のどれか。
2. 最初に見せたいものは、本人・記事・制作物のどれか。
3. 静かで読み物中心か、実験的で記憶に残る表現か。

未回答でも「技術者仲間向け、記事と本人が中心、静かだが特徴のある表現」を仮説として比較案を作れる。
